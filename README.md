# NovelPhoenix — Crimson Night

A personal CSS theme for NovelPhoenix, designed to work with the Stylus browser extension.

## Features

- Dark charcoal background with a subtle red hue
- Burgundy comment cards and borders
- Red commenter names
- Light, readable comment text
- Green like buttons and coral-red dislike buttons
- Lavender links and pink reply controls
- Custom hover effects

## Requirements

- A browser such as Chrome, Firefox, or Brave
- [Stylus browser extension](https://add0n.com/stylus.html)

## Installation

1. Install Stylus in your browser.
2. Open NovelPhoenix and create a new style in Stylus.
3. Set the style's website scope to `novelphoenix.com`.
4. Copy the CSS from `novelphoenix-crimson-night.css` into the editor.
5. Save the style and refresh NovelPhoenix.

## Notes

This theme changes the website's appearance locally in your browser. It does not change the website for other users or modify its server-side functionality.

The theme may need adjustments if NovelPhoenix changes its HTML or CSS selectors.
